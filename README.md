# alpha_trader — 투자 스터디 포트폴리오 트래커

투자 금액을 공개하지 않고 **비중(%)만으로** 서로의 포트폴리오를 비교하고, 제출 시점부터의 수익률을 트래킹하는 대시보드.

대시보드: https://lever-laf.github.io/alpha_trader/

## 왜 금액이 필요 없나

비중만 있으면 수익률은 정확히 계산된다. 구간 수익률 = Σ(비중 × 종목 수익률)이고, 구간별로 chain-link하면 누적 지수가 나온다. 입력 스키마에 금액 필드가 아예 없어서 실수로도 노출되지 않는다.

## 제출 방법

`data/members/<날짜>/<본인slug>.json` 파일을 추가한다. 기존 파일을 복사해 고치는 게 가장 빠르다.

```json
{
  "member": "닉네임",
  "date": "2026-08-15",
  "index": 100.0,
  "note": "이번에 왜 이렇게 담았는지 3줄 이내",
  "holdings": [
    { "ticker": "NVDA", "weight": 30.0 },
    { "ticker": "005930.KS", "weight": 25.0 },
    { "ticker": "CASH", "weight": 45.0 }
  ]
}
```

그다음 `data/manifest.json`의 해당 날짜에 본인 항목을 추가한다.

### 규칙

- **`weight` 합은 100.** 현금은 `CASH`로 반드시 포함한다. 빼면 풀투자로 잡혀 수익률이 왜곡된다.
- **티커 표기** — 미국 `NVDA` / 코스피 `005930.KS` / 코스닥 `247540.KQ` / 암호화폐 `BTC-USD` / 현금 `CASH`
- **`index`** — 첫 제출은 `100.0`. 이후는 계산값이 들어간다.
- **비중이 바뀔 때만 제출.** 월 1회 강제가 아니다. 안 내면 직전 비중이 이어진다.
- **소급 제출 금지.** 지나간 날짜로 비중을 바꿔 넣으면 트래킹이 무너진다.
- 계좌를 나눠 보고 싶으면 `scopes`를 추가한다 (`data/members/2026-07-30/ri.json` 참고).

## 구조

```
index.html                      대시보드. 데이터를 담지 않고 data/ 에서 읽는다
data/manifest.json              스냅샷·멤버 목록
data/instruments.json           종목 마스터 — 이름·테마·레버리지 배수
data/members/<날짜>/<slug>.json  멤버 제출 원본
```

새 티커를 제출하면 `data/instruments.json`에 등록되기 전까지 테마가 "기타"로 잡힌다. 등록은 관리자가 한다.

## 수익률 산출

- 스냅샷 A→B 구간은 A의 비중을 유지했다고 보고 계산한다. 구간 중 매매는 반영하지 않는다.
- 배당 재투자를 반영한 총수익 기준.
- 전부 원화 환산. 환차익이 성과에 포함된다.
- **실효 익스포저** = 비중 × 레버리지 배수. 배수는 일간 수익률 기준이라 보유가 길어질수록 실제 추종 배율은 벌어진다.
- 등수는 매기지 않는다.

## 로컬에서 보기

`file://` 로 열면 브라우저 보안 정책 때문에 `data/`를 읽지 못한다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 공개 범위

이 저장소는 **public**이다. 금액은 어디에도 없지만 닉네임과 보유 종목·비중은 누구나 볼 수 있다. 비공개가 필요하면 저장소를 private으로 돌리고 Cloudflare Pages로 호스팅하면 된다.
